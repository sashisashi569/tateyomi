# 用語集（UI文言の規範）

このファイルは **規範** であり、現状の写しではない。
「現状」列は観測値で、規範と食い違えば現状側を直す。

- **規範表記**: 画面に出す表記。これを正とする。
- **現状**: 2026-11 時点のコードで確認できた表記。
- **判定**: `維持`（現状が規範に一致） / `修正`（現状が規範から外れる） /
  `未決`（変更前に確認） / `未検証`（20文サンプルの外。断定しない）。
- 新しい語は、ここに追記して承認を得てからコードに書く。

## 未決（勝手に決めない）

1. **標準 / 端末**: フォントの出所ラベル。規範案は「標準」（対義語の「追加」と揃う）。
   ただし「端末」の方が出所は明確。どちらかに統一する。
2. **ページ / 頁**: 通常は「ページ」に統一するか、統計の導入文だけ例外を認めるか。
3. **「表示」と「表示設定」**: ボタンは「表示」、画面名は「表示設定」でよいか。
4. **読書進捗の短縮**: 表・バッジでは「進捗」を許すか。
